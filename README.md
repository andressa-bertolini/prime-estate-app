## 🛠️ Installation

1. Clone the repository:

```bash
git clone https://github.com/andressabertolini/prime-estate.git
cd prime-estate
```

2. Install dependencies:
```
npm install
```

3. Create a `.env` file (see `.env.example`):
```
VITE_API_URL=???
```

For a local API, use `VITE_API_URL=http://localhost:3333/api`. Set `VITE_USE_MSW=true` to use MSW mocks instead.

4. Start the development server:
```
npm run dev 
```

The app will run at http://localhost:5173/prime-estate/
